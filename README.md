# 微信下载文件整理

将 Windows 微信下载文件按扩展名归入 `msg\file\整理归纳`，支持预览、普通移动、移动并回收重复副本。
<img width="879" height="534" alt="image" src="https://github.com/user-attachments/assets/98a8697a-7e94-4bb8-be75-5929fe856478" />

分类共 **8 类**：word、excel、ppt、压缩包、DWG、PDF、音频、其他。分类目录按需创建，同名文件自动编号，正式运行生成 `整理统计.txt`。


## 安装

把整个 `wechat_download_files_organizer` 文件夹放入对应位置：

| 工具 | 安装目录 | 手动调用 |
|---|---|---|
| Codex | `%USERPROFILE%\.agents\skills\wechat_download_files_organizer` | `$wechat_download_files_organizer` |
| Claude Code | `%USERPROFILE%\.claude\skills\wechat_download_files_organizer` | `/wechat_download_files_organizer` |

该skill仅支持显式调用。

运行环境：Windows 自带 PowerShell 5.1 或 PowerShell 7；日常不需要 Python、微信 API 或密钥，已有执行策略须允许脚本运行。

## 用法

显式调用 skill 后，Agent会询问用户采取哪项操作:

1. 仅预览. 预览显示各分类的文件数量、大小和总计。
2. 移动.
3. 移动, 且分类归档后删除重复的文件

| 操作 | 结果 |
|---|---|
| 仅预览 | 展示本次计划分类数量、大小和重复分析。不移动 |
| 正式移动 | 分类移动，全部副本保留 |
| 正式移动且删除重复文件 | 分类后检查重复内容，只保留一份，其余放进回收站 |

用户要求只看分类时可以省略重复分析。直接运行脚本、完整扩展名列表及详细规则见 [调用与维护参考](references/REFERENCE.md)。

默认只搜索真实用户的 `C:\Users\<用户名>\xwechat_files` 和 `C:\Users\<用户名>\Documents\xwechat_files`，排除 Codex 沙箱账号；可通过 `-WechatBasePath` 显式指定其他位置。

## 结果与报告

统计明确区分 **本次处理** 和 **整理后库存**。例如原有 100 个文件、本次新增 10 个，普通移动后显示“本次移动成功 10 个，整理后库存 110 个”；若有去重或移动失败，库存以最终扫描为准。skill流程结束后, 会生成 整理统计.txt 
内容参考如下: 

```bash

​本次移动成功：1 个，大小 6.73 KB；移动失败 0 个。
```

## 注意事项

- 移动后，微信聊天记录中的原文件入口可能提示需重新下载；可以从分类目录打开文件。
- 文件夹层级不会保留，但文件内容不修改；同名不覆盖，普通移动不去重。
- 去重按内容判断，不按名称判断；不可回收、文件变化或读取失败时保留并报告，不永久删除。
- 本次 JSON 接口已调整：统计改为 `Run` / `Inventory`，移除旧字段 `SizeKB`、`SearchRoot` 及顶层混合口径统计。自行编写过调用脚本的用户请按参考文档更新。
- 脚本执行失败时查看 [排障与开发说明](references/REFERENCE.md#排障与开发)，不要自动修改系统执行策略。
